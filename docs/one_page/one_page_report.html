Intelligent Decision Support System Using Generative AI and Machine Learning

A Multi-Agent Platform that Turns Business Questions and Data into Verified, Explainable Decisions

GUIDED BYDr. Arjun Jadhaw

GROUP MEMBERSRaj Vishwas Patil · Bhavesh Vinod Patil · Chaitany Rajesh Naval · Varun Darshan Patil

Abstract

IDSS is a web application that turns a business question into a verified, explained decision. A user uploads a dataset and asks a question in plain English. Generative AI agents understand the question; an AutoML engine (scikit-learn, XGBoost, LightGBM, Optuna) trains and tunes models; a verifier checks the results; SHAP and what-if analysis explain them; and an insight agent writes recommendations that use only computed numbers, plus a PDF report. Built with Python, FastAPI, Streamlit and SQLite, it is inspired by the AutoML-Agent framework (ICML 2025).

Introduction

Background

Businesses collect data but have few data scientists. AutoML tools stop at a trained model, and LLM assistants can invent numbers. Managers need answers they can check and act on.

Problem Statement

  • Business users cannot build ML models on their own
  • Questions must be turned into ML tasks by hand
  • AutoML tools return a model, not a decision
  • LLM-written code can fail; LLMs can invent numbers
  • Results are rarely verified, explained or reported

Objectives

  • Turn a plain-English question into a validated ML task
  • Train and tune models automatically within a budget
  • Check every model against the goal and a baseline
  • Explain results with SHAP, what-if and risk tiers
  • Write insights from computed facts, plus a PDF report

Advantages & Disadvantages

Advantages

  • Questions in plain English
  • Every model is checked
  • Clear drivers and what-if
  • Runs offline without an LLM

Disadvantages

  • Free-text questions and full insights need an LLM API
  • Evaluated on synthetic data
  • Finds patterns, not causes

Conclusion

IDSS pairs LLM agents, which understand the question and explain the answer, with tested code that trains and verifies the models. From one plain-English question, a non-expert gets a verified model, its key drivers, what-if answers and a clear PDF report.
